# 課前準備

請在上課前完成以下步驟，現場只做確認。每一步都附檢查指令，輸出符合「預期結果」才算完成。

指令分 Windows（PowerShell）與 macOS（Terminal）兩種，選自己的系統照做。裝完新工具後，請關掉終端機再重新開一個，新指令才會生效。

## 本機必備

### 1. 安裝 uv

Windows（PowerShell）：

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

macOS：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

檢查：

```bash
uv --version
```

預期結果：印出 `uv 0.x.x` 之類的版本號。

### 2. 安裝 Python 3.11～3.13

已經有 Python 3.11～3.13 的人可以跳過。沒有的話，用 uv 安裝最簡單：

```bash
uv python install 3.13
```

檢查：

```bash
uv python find 3.13
```

預期結果：印出一個 Python 執行檔路徑，沒有錯誤訊息。

### 3. 取得課程專案

課程專案在 <https://github.com/tsai0705/gdgc-adk-agent-deploy>，兩種方式擇一：

- 有裝 Git：`git clone https://github.com/tsai0705/gdgc-adk-agent-deploy.git`，得到 `gdgc-adk-agent-deploy` 資料夾。
- 沒裝 Git：在 repo 頁面按「Code」→「Download ZIP」，解壓後得到 `gdgc-adk-agent-deploy-main` 資料夾。

這個資料夾就是「專案根目錄」，之後的指令與 Claude Code 都在這裡執行。

檢查（在專案根目錄執行）：

```bash
ls pyproject.toml
ls course_agents/hello_agent
```

預期結果：第一個指令列出 `pyproject.toml`，第二個指令列出 `agent.py` 等檔案，都沒有錯誤訊息。

### 4. 建立 Gemini API Key

1. 打開 <https://aistudio.google.com/apikey>，用自己的 Google 帳號登入。
2. 按「Create API key」建立一把 Key。
3. 把 Key 存在只有自己看得到的地方（例如密碼管理器）。

檢查：回到上面的頁面，列表裡看得到剛建立的 Key。

Key 只會在上課時由自己貼進 `.env`。不要貼進聊天、AI 對話、投影片或 Git commit。

## 上雲另外準備

### 5. 安裝 gcloud CLI

到 <https://cloud.google.com/sdk/docs/install> 下載自己系統的安裝程式，照畫面安裝。

檢查：

```bash
gcloud --version
```

預期結果：輸出裡有一行 `Google Cloud SDK` 加版本號（前面出現 Updates are available 的提示可以忽略）。

### 6. 建立 GCP project 並綁定帳單

盡量使用新的 Google 帳號，新帳號會有 $300 試用金。

1. 打開 <https://console.cloud.google.com>，用要上課的帳號登入。
2. 依畫面啟用免費試用並建立帳單帳戶（需要綁信用卡）。
3. 上方專案選單按「新增專案」，建立一個專案，記下「專案 ID」（不是專案名稱）。
4. 到「帳單」頁面，確認這個專案已連結到剛建立的帳單帳戶。

檢查要等第 7 步登入後才能跑，見第 7 步。

### 7. 用 gcloud 登入並設定專案

把 `<專案 ID>` 換成自己的專案 ID：

```bash
gcloud auth login
gcloud config set project <專案 ID>
gcloud auth application-default login
```

`gcloud auth login` 與 `application-default login` 都會開瀏覽器，請用同一個帳號登入並允許。

檢查：

```bash
gcloud auth list
gcloud config get-value project
gcloud billing projects describe <專案 ID>
```

預期結果：

- `gcloud auth list`：自己的帳號前面有 `*`。
- `gcloud config get-value project`：印出自己的專案 ID。
- `gcloud billing projects describe`：輸出裡有 `billingEnabled: true`。
